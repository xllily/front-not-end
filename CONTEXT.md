# front-not-end project context

## Product

front-not-end helps frontend developers use an existing AI Coding Agent to
deliver production-capable full-stack projects. The user describes the product
and supplies facts the Agent cannot infer. The Agent owns the backend technical
work.

front-not-end does not replace the Agent's model loop, session runtime, or tool
runtime.

## Public repository

Every tracked file is a finished product result. It must define, implement,
verify, package, or explain the product as it exists now.

Do not commit working notes, exploratory analysis, unfinished plans, review
trails, raw run output, or decision history. Public documentation states the
current behavior, contract, support boundary, and reproducible evidence. It
must stand on its own without referring to private working material.
